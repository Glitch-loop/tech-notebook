## User story

User story is a concept used to describe technical features of a product in non-technical simple language.
A common template used to describe a user story is:
> **As a {type of user}, I want {goal} so that I {receive benefit}.**

To give an example, imagine we are developing a website, so from requirements this user story arise:
	**As a customer, I want to be able to create an account so that I can see my previous purchases.**
