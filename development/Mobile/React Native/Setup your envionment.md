### Emulators for development

For development purposes it might be useful to use an emulator, this since you can play with the variables of the one (size, capacity, memory, etc.), but it is advisable as well as you can you to use a device for developing this because it is closer to a real production environment. In addition, if you use an emulator, try to develop in a machine with high capacity because emulators are hard to compute.
