### Jest and Jest-expo
For testing your applications you can use `jest-expo`
This library is part of the expo environment and it's used to test your applications.

Under the hood, `jest-expo` uses `Jest` library that helps you to mock your applications, in this way, `jest-expo` is a _preset for jest for mocking the native part of the Expo SDK and handling most of the configuration required for your Expo project._

Between the type of tests you can do, we have:
- unit test
- Snapshot test

[jest-expo docs](https://docs.expo.dev/develop/unit-testing/)
