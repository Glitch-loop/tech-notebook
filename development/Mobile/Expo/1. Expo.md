# What is it?
Expo is a framework that makes developing Android and iOS apps easier.

This framework provides:
- file-based routing.
- Standard library of native modules.

In addition, Expo's community created **Expo Application Service (EAS)** that is a set of services that complements the Expo framework.

According to React Native's documentation: 
> Expo is a production-grade React Native Framework. 

> Expo's Framework is free and open source with an active community on [Github](https://github.com/expo) and [Discord](https://discord.com/invite/expo).

In addition, ***Expo's team*** *works in close collaboration* with the ***React Native team at Meta*** to bring the latest React Native features to the Expo SDK.

# What is Expo App?
This is a shorthand term that is used to refer that an React Native app uses Expo tools.
Expo as framework provides a variety of tools:
- Expo Router
- Expo SDK
- Expo CLI
- Continuous Native Generation

This doesn't necessarily mean that all the project depends on Expo but since there a lot of functionalities which Expo provides and React Native team at Meta don't, the dependency on Expo shows up.

In the end, Expo App is another React Native App.

# What is Expo GO?
Expo GO is a development tool for visualizing your application directly on the device. 
You might see this as an alternative of using an emulator.
