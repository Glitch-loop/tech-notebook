# What is it?
Expo is a framework that makes developing Android and iOS apps easier.

This framework provides:
- file-based routing.
- Standard library of native modules.

In addition, Expo's community created **Expo Application Service (EAS)** that is a set of services that complements the Expo framework.

According to React Native's documentation: 
> Expo is a production-grade React Native Framework. 

> Expo's Framework is free and open source with an active community on [Github](https://github.com/expo) and [Discord](https://discord.com/invite/expo).

In addition, ***Expo's team*** *works in close collaboration* with the ***React Native team at Meta*** to bring the latest React Native features to the Expo SDK.
