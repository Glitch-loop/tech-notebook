### OTA
An OTA (Over-the-Air) manifest is ==a crucial metadata file within a software update package that tells a device exactly _what_ to update, _where_ to find the new files, and _what conditions_ must be met before and after installation==, acting as a blueprint for wireless updates of firmware, apps, or system software.
